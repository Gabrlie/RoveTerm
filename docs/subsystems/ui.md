# ui

`ui/` 是 Svelte 5 + TypeScript 前端：终端视图、文件面板、标签与分屏、主机管理、actions 表、i18n 字典和设计 token。前端只持有 `SessionId` / `HostId` / `FsId`，会话本身活在 Rust 侧。

## TermView

`TermView` 接收一个 `open(size, onOutput) => Promise<SessionId>` 函数：挂载后先按容器尺寸计算终端尺寸，再调用 `open` 启动会话，因此 shell 一开始就拿到正确的尺寸。

- 输出通过 IPC Channel 到达：`ArrayBuffer` 直接写入 xterm；`{ progress }` 消息由 `connectLog.ts` 格式化为一行连接日志（连接、握手、host key、逐个凭据的尝试与拒绝、认证成功）写入终端，连接成功后在第一段终端输出到达时清空，连接失败时保留以便查看停在哪一步；`{ exit }` 消息在终端中显示退出提示，并调用 `onexit`。
- 输入通过 `onData` 调用 `sessionWrite`；会话打开之前的输入会被丢弃。
- 面板在连接完成前被关闭时，稍后返回的会话立即由 `sessionClose` 关闭，之后到达的输出和错误都被忽略，不会留下后台会话。
- 容器尺寸变化经 `ResizeObserver` 和 `requestAnimationFrame` 合并后调用 `fit`，行列数变化时才调用 `sessionResize`。
- macOS、Windows 和 Android 上按需动态加载 WebGL 渲染器；Linux 桌面（WebKitGTK）在同时存在多个 GL 上下文时，较早的 WebGL 终端不再重绘，因此使用 DOM 渲染器。WebGL 上下文丢失时退回 DOM 渲染器并立即重绘。
- 每次 `fit` 之后重绘可见区域，避免画布尺寸变化后留白。
- 注册 `attachCustomKeyEventHandler`，应用快捷键不会再发给 shell。
- 终端配色按界面亮暗分别取偏好中的 `scheme_light` / `scheme_dark`（`theme.ts`），两个槽位都可以选任意方案，未知 id 退回同亮度的 RoveTerm 配色；终端周围的 `--term-bg` / `--term-fg` 跟随所选方案。修改偏好后已打开的终端立即换色。
- 字体、字号、行高取自偏好设置，修改后对已打开的终端立即生效。字体栈依次为用户选择的字体、`--font-mono` 内置字体栈（以 `monospace` 结尾）、内置的 Symbols Nerd Font Mono；符号字体放在最后，因为第一个可用字体决定行高度量。创建终端和切换字体前先等待字体加载，避免字形在加载前被测量或缓存。
- 组件提供 `focus()`、`selection()`、`paste(text)` 方法。

## 编辑组与标签

工作区与 VSCode 的编辑组相同：一棵分屏树（`split { dir, ratio, a, b }`，`row` 左右、`column` 上下，`ratio` 限制在 0.1–0.9）的叶子是编辑组，每个组有自己的标签栏和标签，一个标签就是一个终端或文件面板（`PaneState`）。

- 每个组是一张浮动圆角卡片，组与组之间隔开 `--gap-panel`，间隙就是拖动调整大小的把手；有多个组时，聚焦的组带强调色轮廓，其他组的当前标签显示得淡一些。点击组内任意位置即聚焦该组；底部、右侧面板以及复制粘贴都跟随聚焦组的当前标签（`workspace.focusedPane`）。
- 组的标签栏依次是：主页按钮、各标签（图标右下角的状态点：绿色已连接、黄色闪烁连接中、红色失败、灰色已退出；关闭按钮只在悬停和当前标签上显示；中键关闭。已保存主机的终端和文件标签以主机名称为标题并跟随改名，shell 设置的标题如 `user@host: dir` 只作为悬停提示；本地终端和快速连接显示 shell 设置的标题）、"+"（让该组显示主页）、向右拆分，以及有多个组时的"关闭分组"。组的 `active` 为 `null` 时显示主页。
- 新标签（`App+T`、连接主机、打开文件）开在聚焦组里当前标签之后。`Ctrl+Tab` 在聚焦组内循环，主页排在最前；`App+1…9` 切到聚焦组的第 N 个标签；`App+]`、`App+[` 在组之间切换焦点。
- 标签右键菜单：关闭、关闭其他标签、关闭右侧标签、向右或向下拆分（在新组中再打开同一目标）、移到右侧或下方新分组（标签本身移过去，组内只有它时不显示）、移到下一个分组、左移、右移。
- 拖动标签（指针事件，`src/lib/tabs/tabDrag.svelte.ts`；不用 HTML 拖放，Windows 上窗口的文件拖放处理会吞掉它）：拖到任意组的标签栏上按插入位置重排或移入该组（强调色竖线标出位置）；拖到组的内容区中部移入该组，靠近某条边（25% 以内）则在那一侧新建一个组并移入，落点以半透明强调色区域预览。移动标签不会重建终端或断开会话；组被移空后自动移除。
- 所有标签的内容（`PaneView`）在同一层渲染，按所属组的内容区（卡片减去 40px 标签栏）绝对定位，组卡片里只放标签栏和主页；因此切换、拆分、调整大小或在组之间移动标签都不会卸载视图。
- 拆分（`App+D` / `App+E` 或标签栏按钮）在聚焦组旁新建一个组，打开与当前标签相同的目标（SSH 由后端复用已有连接）；当前组显示主页时新组也显示主页。"在终端旁打开文件"向右拆出一个组，里面是该主机的文件标签。
- 关闭标签后组显示相邻标签；组没有标签且还有其他组时整组移除，最后一个组则回到主页。`App+W` 关闭聚焦组的当前标签，组在主页时关闭该组。
- 组内所有标签都保持挂载，非当前的用 `visibility: hidden` 隐藏，尺寸不变；拆分、调整大小或切换标签都不会重新挂载终端或重启会话。
- 首页列出已保存主机，按 `last_connected_at` 降序排列，从未连接的按名称排在后面；卡片为紧凑的两行（名称与运行中的转发数；经由、用户与"x 分钟前连接"），网格每列至少 220px，点击连接，悬停显示浏览文件和编辑。终端连上已保存主机后刷新主机列表，排序随之更新。

- 本地 shell 以退出码 0 退出时自动关闭标签；其他情况保留并显示退出提示：远程会话没有退出码时写"连接已断开"，而不是"代码 ?"。
- 会话结束后终端底部出现提示条（连接已断开 / 会话已结束 / Shell 已退出），带"重新连接"（本地为"重新启动"）和"关闭"；在终端里按 Enter 同样重新连接（`workspace.reopen` 换成新面板）。聚焦的面板已结束时，服务器状态页回到骨架屏，重新连上后继续采样。

## 文件面板

文件面板是一种面板类型（`PaneTarget` 的 `sftp`），和终端一样参与标签与分屏。

- 打开方式：在主机栏中点主机的"浏览文件"按钮，新开一个标签；或在 SSH 终端中按 `App+O`，在右侧分屏打开同一主机。对快速连接的终端同样有效。
- `FileBrowser` 挂载时调用 `sftp_open`，卸载时调用 `sftp_close`。需要密码时走与终端相同的 `ssh.credentials_required` → 密码框 → `workspace.reopen` 流程。
- 文件图标按类型取色：目录用强调色，压缩包、图片、脚本与源码、配置、文本各用一种系统色，其他为灰色。列表获得焦点时选中行为强调色实底，失去焦点时为灰底。
- 双击目录进入，双击文件下载到系统下载目录；路径栏可以直接输入路径。单击选择，Ctrl/⌘ 单击多选，Shift 单击连选。
- 列表获得焦点时：方向键移动选择，Enter 打开，Backspace 返回上级，Delete 删除，F2 重命名，Ctrl/⌘+A 全选。
- 上传通过系统文件选择框（`tauri-plugin-dialog`，只授予 `dialog:allow-open`），或把文件从系统拖到面板上。上传时若当前目录已有同名项、下载时若本地目标目录已有同名项（由 `transfer_local_clashes` 检查），都询问替换、保留两者还是跳过。
- 面板底部列出与该主机相关的传输（`transfer-update` 事件），显示进度并可取消；上传到当前目录的传输完成后自动刷新列表。
- 是否显示隐藏文件取自偏好 `files.show_hidden`，工具栏按钮切换时写回偏好。

## 端口转发

- 在主机栏中点主机的"端口转发"按钮，或在命令面板中运行"管理当前主机的端口转发"，打开该主机的转发对话框。
- 对话框列出规则：类型（L / R / D）、地址、状态（运行中及连接数、失败原因、已停止），可以启动、停止、编辑、删除。修改规则会停止正在运行的转发。
- 编辑器按类型显示字段和说明；本地或动态转发的监听地址不是回环地址时显示警告。勾选"自动启动"的规则在打开该主机的终端时启动。
- 启动时需要密码（`ssh.credentials_required`）就在该规则下显示密码框，可以勾选记住密码。
- `forwards.svelte.ts` 监听 `forward-update` 事件；主机栏在有运行中的转发时，在主机名旁显示转发数。

## 会话恢复

编辑组与标签变化后 1.5 秒，把 `workspace.snapshot()` 经 `workspace_save` 记入 journal。快照（`src/lib/workspace/snapshot.ts`，版本 2）记录分屏树、每个组的标签目标（本地、已保存主机 id、快速连接地址、文件面板）与当前标签、聚焦的组，不含任何凭据。启动时 `workspace_load` 读取最新快照，经 `parseSnapshot` 校验后恢复（最多 64 个标签）；版本 1 的快照（每个标签各自分屏）转换为一个组，按阅读顺序包含原来所有面板，并显示原当前标签中聚焦的那个。恢复的标签先处于 `deferred` 状态，只显示标题，第一次成为所在组的当前标签时才连接，因此不会同时发起多条连接或弹出多个密码框。

## 工作区面板

终端区域右侧和下方各有一个可开关、可拖动边缘调整大小的面板，开关状态和尺寸按设备记在 localStorage。它们都跟随当前聚焦面板所在的远程主机（`remoteSourceOf`），主机变化时重新挂载；聚焦本地终端或首页时显示提示。

- 右侧图标栏（`ActivityRail`）在窗口最右侧，与标题栏同材质、不做卡片：
  - 上段是右侧面板的页面开关：服务器状态、AI（有待审批时显示数量角标）、快捷指令。同时只开一个面板，点击已打开的那页即收起，与 VSCode 的辅助侧栏相同；打开的页面按设备记在 localStorage。
  - 中段：文件（开关底部文件面板）、端口转发（打开聚焦主机的转发），聚焦的不是远程主机时禁用。
  - 底段：快速连接、从系统导入。
  - 全部经 actions 表触发：`panel.status`、`ai.open`、`panel.snippets` 开关对应页面，`panel.right`（`App+L`）开关上次打开的页面。标题栏右侧仍有侧栏、底部面板、右侧面板三个开关（右侧面板按钮开关上次打开的页面），与图标栏并存。
- 底部状态栏（`StatusBar`）在窗口最下方，高 26px：
  - 左侧：聚焦会话的状态点（已连接、连接中、失败、已结束）、名称（已保存主机为主机名，本地终端为"本地终端"）、`用户@主机`、已连接时长（会话开始时记在 `PaneState.connectedAt`）、活动会话数、运行中的端口转发数。
  - 右侧：AI 待审批数（点击打开 AI 面板）、同步状态（已设置同步时显示，悬停为上次同步时间，点击立即同步，进行中转动、失败标红）、新建本地终端、外观菜单（自动、浅色、深色，写入偏好）、命令面板、当前时间（每到整分钟刷新）。
  - 时长与时间的格式化在 `layout/status.ts`，有单元测试。
- 右侧面板只显示当前页面，顶部是页面标题与关闭按钮：
  - 状态：每 3 秒调用 `server_stats` 采样（聚焦终端的会话连上时立即采样；单次采样 20 秒无应答即放弃，下次照常），用两次采样的差值计算使用率和速率，分卡片显示：系统（主机名、操作系统、响应时间、运行时间、内核；经跳板机时响应时间按段显示为 `12+85 ms`，10 ms 以下保留一位小数，标签后用小字注明各段，如"（跳板 + 目标）"）、CPU（平均使用率、负载，以及每核最近 2 分钟使用率的折线图 `CoreChart`：每行放尽量多的图（每图至少约 110px，超过 8 核时改为只显示数值的紧凑图），再均分各行，如窄面板里 4 核排成 2 × 2）、内存（物理内存与交换分区）、网络（各网卡上下行速率，按流量排序，超过 6 个时可展开）、磁盘（每个挂载分区的占用）。只使用已有连接。没有聚焦远程主机（`source` 为空）、尚未连接或第一次采样返回前，都显示与正式卡片同结构的骨架屏；只有非 Linux 服务器等真正的错误显示说明文字。骨架屏（通用类 `.skeleton`，带扫光动画），数据到达后直接替换。CPU 使用率要两次采样才能算出，比其余数据晚一轮，在此之前 CPU 卡片的平均使用率和每核折线图保留骨架。每台主机最近一次采样、CPU 历史和速率按 `sourceKey` 缓存在模块级（随窗口存活），切换面板或重新打开右侧面板时立即显示缓存内容，再继续刷新。
  - 快捷指令：搜索、新建、编辑、删除；"插入"以 bracketed paste 写入聚焦终端（不执行），"运行"把命令（多行按行）连同回车一次写入会话，保证回车不会先于命令到达。
- 底部面板（`App+J` 或图标栏的文件按钮）：聚焦终端连接成功后，用 `FileBrowser` 显示其所在主机的文件，复用同一条共享连接，不会自行发起连接或询问密码。聚焦的是文件面板时不重复显示。面板没有单独的标题行，关闭按钮在文件工具栏最右侧（`FileBrowser` 的 `onclose`）。没有聚焦远程主机时显示 `FilesSkeleton`（工具栏与文件行的骨架），文件浏览器连接中和第一次列目录完成前都显示骨架行，中间不会闪出空白列表。最近显示过的 4 台主机各保留一个 `FileBrowser` 实例，不在当前主机的隐藏而不卸载，切换回来时目录、列表和选择保持原样，超出时关闭最早的一个；主机的地址、用户、端口或路由（含跳板主机的）改变后，该主机旧的实例关闭（它仍在旧连接上），按新配置重新打开，服务器状态的缓存同样按此区分（`sourceKey` 包含 `hosts/reach.ts` 的 `reachKey`，有单元测试）；底部面板首次打开后一直挂载，关闭只是隐藏。

## AI 面板

右侧面板的"AI"页（图标栏、`App+I` 或"视图"菜单打开），`src/lib/ai/`，布局与 VSCode 的 Agent 聊天相同：

- 每个主机上下文一段对话（`ai.svelte.ts` 的 `Chat`）：聚焦标签所在的已保存主机、快速连接地址，或本机。切换标签时面板跟着切换到对应主机的对话，关闭面板不会丢失对话。首次发送时用 `ai_start` 启动所选 Agent；顶部工具行是主机名，以及新对话、历史、AI 设置按钮。
- 消息不用气泡：用户消息是右侧的浅色块，回复是整宽 Markdown，思考折叠为一行，计划是顶部可折叠的清单。没有对话时显示说明与几条示例提示（点击填入输入框）；没有任何 Agent 时引导去设置。
- 每个操作是一行可展开的条目：图标、动词与对象（如"运行 `uptime`"）、状态（进行中、✓、✗、已拒绝并划掉）；展开看输出。连续两个以上未经询问且成功的操作折叠为"已执行 N 个只读操作"。需要批准的操作先显示为内联审批卡片，回答后变回一行，执行结果填进同一行（`chatview.ts` 的 `approvalFor`，布局与状态的纯函数有单元测试）。Agent 自带工具的行显示其标题与命令（从 `rawInput` 取，`bash -lc` 显示为脚本本身）或第一个文件；已允许且 Agent 也报告了同名工具调用的审批不再重复显示。标题、命令与路径过长时在行内截断（悬停看全文），回复中的长路径换行，不会撑宽面板。
- 连接问题：Agent 在重连时转发的警告（如 Codex 的"stream disconnected… (os error 10061)"）不作为回复文字，而是一行"与模型服务的连接中断，正在重试（N）"；之后 Agent 继续回复则变为"连接已恢复"；回合因连接失败结束时变为"无法连接模型服务"，带"重试"按钮（重新发送上一条消息），展开可看原因。识别规则在 `chatview.ts` 的 `connectionProblem`。
- 审批卡片按风险着色，显示操作（Agent 自带工具显示其标题，以及 Agent 给出的理由或参数）、所在主机（Agent 自带工具标为"本机（Agent 自带工具）"）、命令或路径、风险原因（`ai.reason.*` 文案）。按钮为拒绝、本次对话允许（仅在可记住时）、允许一次；危险操作须先勾选"我了解……"才能允许。等待批准时输入框上方提示"等待你的批准"，图标栏与状态栏显示数量。
- 回复中标为 shell 的代码块带"插入"（以 bracketed paste 填入聚焦终端，不执行）和"复制"，其他代码块只有"复制"。
- 底部输入卡片：上方是上下文标签（主机，以及只有终端图标的开关（悬停显示说明，关闭时图标变淡）：打开时 Agent 能读取聚焦终端当前显示的内容，关闭后仍能用自己的会话在主机上执行命令，只是看不到用户的终端画面；对话开始后固定）；多行输入随内容增高，Enter 发送、Shift+Enter 换行；底行是 Agent 选择器（分组为"内置助手"的各服务商与"本机智能体"，经 npx 运行的注明）、审批模式按钮（只显示图标与简称，点开的菜单列出询问、审阅、自动及各自的完整说明，菜单与输入卡片同宽）和发送按钮，回合进行中变为停止。已开始的对话切换 Agent 时开始新对话，保留模式与终端开关。
- 顶部工具行显示对话标题（用户起的名字，否则为第一个问题），点击即可改名（Enter 确认、Esc 放弃）；对话开始前改的名字在开始时写入。
- 输入卡片底行的模型按钮显示当前模型，菜单列出 Agent 提供的设置（模型及说明、推理强度等，开关类设置显示为开关）；本机智能体在对话开始前点击该按钮会先启动 Agent（不发消息）以取得设置；内置助手的推理强度名称按语言显示；内置助手在对话开始前就列出服务商的模型，开始前选的设置在 Agent 启动后应用。审批模式按钮只显示图标，悬停显示名称。模式按钮左侧的用量圆环显示智能体报告的上下文占用（80% 起变为警示色），点开列出上下文与 Codex、Claude Code 的套餐额度（5 小时、每周等窗口的进度条与重置时间，可刷新；`ai/quota.ts` 有单元测试）。
- 历史（`AuditDialog`）：列表显示标题；所选对话可改名，"继续对话"把它还原到其主机的对话中（`chatview.ts` 的 `itemsFromRecords` 从记录还原条目，连接问题仍显示为连接行；还原的审批不带请求序号，继续后的会话从 1 重新编号的审批由 `waitingApproval` 匹配最新的待回答项），下一条消息以同一 Agent 继续；不在当前主机时提示切换到该主机的标签。记录于支持继续之前的对话不能继续。
- 启动或登录失败的提示带"AI 设置"入口；凭据库锁定导致的失败带"解锁"按钮。
- 顶部的历史按钮打开审计回看（`AuditDialog`）：左侧是最近的 AI 会话（主机、时间、Agent），右侧是所选会话的时间线：提示、回复、审批请求与回答、每条命令（退出码，输出可展开）、读写的文件、回合结束；拒绝与危险项以红色标出。记录到界面行的转换在 `audit.ts`，有单元测试。
- Agent 的回复不可信，Markdown（GitHub 风格：表格及对齐、删除线、任务列表、嵌套列表、含块的引用、硬换行、自动链接）由 `markdown.ts` 用 `marked` 的词法分析得到 token 再转成自有结构，`Markdown.svelte` 递归地以普通元素和文本节点渲染，从不使用 HTML；回复中的 HTML 原样显示为文字，图片不加载，只显示其说明；链接只显示文字，悬停时显示地址，不会在应用内跳转。

## 密钥库

主机栏左下角的"密钥库"按钮或命令面板的"密钥库"打开 `KeysDialog`（不再放在"主机"菜单中）。主机栏底部从左到右是密钥库、凭据库需要处理时的提示（锁定或设备密钥丢失，点击解锁或重置；已解锁时不显示）和设置齿轮。`KeysDialog` 与设置窗口同样布局：左侧是搜索框与密钥列表（算法标签，缺私钥时标注），"生成密钥""导入密钥"在对话框底部与"完成"同一行；右侧是标题（可改名、删除）和分组卡片：概览（算法、指纹可复制、使用它的主机）、公钥（复制、编辑）、私钥（解锁后显示与复制）、安装到主机。生成与导入表单也用分组卡片。

- 生成：名称、类型（Ed25519、ECDSA P-256、RSA 3072）、注释、可选的私钥密码。
- 导入：粘贴私钥，或点"从文件读取密钥"：`~/.ssh` 中只有一把默认密钥时直接读取，有多把时弹出菜单列出它们和"选择其他文件"，没有时打开文件选择框；所选文件是私钥还是公钥由后端识别（`key_load_file`），另一半从旁边读取，名称为空时用文件名填入；公钥可留空（使用从私钥推出的公钥，保留私钥中的注释）或自行填写；加密私钥缺少密码时高亮密码框。
- 编辑公钥：在详情中修改公钥（例如改注释），保存前校验与私钥配对。
- 查看：算法、指纹、公钥（可复制）；"显示私钥"解锁后调用 `key_reveal` 显示私钥，可复制。
- 改名、删除（仍被主机使用时提示失败原因）。
- 安装公钥到主机：选择已保存主机后调用 `key_install`；主机还不能登录时显示密码框，以 `password_kind = "password"` 连接。
- 主机编辑的认证方式"密钥库中的密钥"用下拉框选择密钥，旁边的"管理密钥库…"在编辑框之上打开密钥库，关闭后列表自动更新。每台主机单独保存私钥的旧方式只对已在使用它的主机显示。

确认操作统一使用 `ask()`（`src/lib/ui/confirm.svelte.ts`），由 `ConfirmHost` 渲染为主题化的对话框，不使用浏览器的 `confirm()`。

## 设置

主机栏底部的齿轮按钮或 `App+,` 打开设置对话框。左侧是分区导航，右侧是分组表单（`form-group` / `form-row`），每个分区一个组件（`src/lib/settings/sections/`）。修改立即生效：`editPrefs()` / `editDevice()`（`edit.svelte.ts`）修改一份副本后交给后端校验保存，被拒绝时在底部显示原因，不需要统一保存。

| 分区 | 内容 |
|---|---|
| 外观 | 主题（自动 / 浅色 / 深色缩略图）、强调色色板、界面文字大小、语言、半透明窗口（本机） |
| 终端 | 字体（从 `fonts_monospace` 列出的本机等宽字体中选，已保存但不再安装的仍保留）、字号、行高与预览；浅色与深色模式配色（带色卡）；光标样式与闪烁、滚动缓冲、选中即复制、右键行为、响铃 ；SSH 连接（只在本机）：连接超时、保活间隔、允许丢失的保活次数，对之后建立的连接生效 |
| 文件 | 显示隐藏文件、删除前确认、同名文件的默认处理、下载位置（本机）、同时传输数（本机） |
| 服务器状态 | 刷新间隔 |
| 快捷键 | 只读列出 actions 表，可按名称或按键搜索 |
| AI | 模型服务商：列表（★ 默认模型及其他模型数、接口格式、是否已存 key），编辑、移除（连同本机 key）；"添加服务商"从预设（OpenAI、Anthropic、DeepSeek、OpenRouter、Ollama、其他兼容接口，`settings/providers.ts`，有单元测试）预填地址与格式，表单含名称、接口格式、地址、模型（"获取模型列表"按地址、格式与 key 拉取，列表可搜索、多选，勾选项旁的星标为默认模型，其余勾选的可在对话中切换；获取失败或服务没有列表时手动输入模型名添加，`providerModels` / `mergeListed` 有单元测试）、推理强度（默认或 minimal 至 max）、API key（只写不回显），"测试"发一个最小请求并显示模型回复或错误。本机智能体：检测到的智能体（程序或"通过 npx 运行"）可开关，按命令添加的可移除，每项可单独保存 API key；"按命令添加智能体"填名称、命令、参数；登录方式（有 key 用 key 否则用账户 / API key / 智能体账户）。新对话：默认 Agent（或第一个可用的）、默认审批模式与说明。审批：追加只读程序与始终危险的文字（每行一项，失焦时保存） |
| 同步 | 分两步：先选存储并"连接"（文件夹：可粘贴路径或选择；WebDAV：服务器地址、文件夹名（默认 `RoveTerm`，与地址拼成目录 URL，`src/lib/sync/webdav.ts`）、用户名、密码），连接成功即保存在本机；再按存储中是否已有空间自动显示"加入并同步"（一次同步密码）或"创建并同步"（密码与确认），可"更换存储位置"。已设置时：位置、已同步记录数、上次同步结果、立即同步、在本设备停用；本机没有 WebDAV 密码时只要求重新输入它。输入内容保存在页面之外的 `draft` 中，切换分区、存储类型或出错后都不会丢失；错误与结果以悬浮通知显示 |
| 关于 | 版本与许可说明 |

终端固定使用 4.5 的最低对比度（xterm.js `minimumContrastRatio`）：假定深色终端的程序输出的浅色文字，在浅色配色下会被调深到可读。各项在使用处读取 `prefs`：终端的光标、滚动缓冲、选中即复制、右键（菜单：复制、粘贴、全选、清屏；或直接粘贴）、响铃（短暂的强调色闪烁）由 `TermView` 应用，修改后对已打开的终端立即生效；文件面板的同名处理不为"每次询问"时直接按设定执行，关闭删除确认后直接删除，下载默认存到设定的下载位置；状态面板按刷新间隔采样。


同步状态在 `src/lib/sync/sync.svelte.ts`：vault 解锁后自动同步一次，之后每 5 分钟一次；一轮写入了远程变更时刷新主机、密钥库和偏好，并递增 `generation`，自行加载数据的视图（快捷指令）据此重新加载。
## 主机与凭据

- 主机前是系统图标 `HostIcon`（`src/lib/hosts/HostIcon.svelte`）：品牌色圆角方块上的白色标志（浅色品牌色用深色标志），按 os-release 的 `ID` 再按 `ID_LIKE` 在 `osIcons.ts` 中查找，来源见同目录 `OS-ICONS.md`；未检测或不认识的系统显示灰色方块加服务器图标，悬停显示 `PRETTY_NAME`。保存的主机在本次运行中第一次建立终端会话时调用 `host_detect_os` 检测一次（`hosts.connected`）。侧栏和主页共用。
- 主机名下一行显示连接路线与用户名（`src/lib/hosts/route.ts`）：`SSH · root`、`经 bastion · root`、`SOCKS5 代理 · root`；地址不在列表中出现，只在悬停提示里显示，避免截图或共享屏幕时暴露。侧栏与主页相同。
- 侧栏按分组列出主机，搜索时匹配名称、地址、用户名、分组和标签；双击或按 Enter 连接。悬停时只显示"连接"和"更多"两个按钮，右键、"更多"或 ContextMenu 键打开菜单：连接、浏览文件、端口转发、编辑、复制主机（不复制已保存的凭据）、删除。删除时确认框注明将关闭该主机已打开的标签数，删除后这些终端和文件标签一并关闭。主机在其他设备上被删除（同步后不在列表中）时，没有活动会话的标签显示"这台主机已被删除"和关闭按钮，右侧状态面板显示骨架屏，不再显示查找失败的错误。
- 经跳板机或代理连接的主机在名称后显示小图标，悬停提示经由的跳板机或代理，不占用地址那一行。
- 标题栏右侧的侧栏按钮或 `App+B` 收起和展开侧栏；是否展开按设备记在 localStorage。侧栏顶部直接是搜索框，快速连接、新建主机、从系统导入和密钥库都在应用菜单里。
- 连接前，如果主机使用"每次询问"认证，或者使用密码认证但没有保存密码，先弹出密码框；用户可以勾选"记住密码"，连接成功后由后端写入 vault。
- 终端打开失败时记录到面板的 `failure`，在面板底部显示失败原因和操作：重试、输入私钥密码（缺少 passphrase 时）、使用密码登录（对密钥主机以 `password_kind = "password"` 重连，这种密码不能记住）、编辑主机、关闭。
- 打开面板时如果后端返回 `ssh.credentials_required` 或 `ssh.passphrase_required`，弹出密码或私钥密码框，再用新面板替换原面板重新连接（`workspace.reopen`）。密钥主机可以勾选"记住私钥密码"，成功后存为 passphrase。
- 一次性密码只保存在面板状态中，会话打开后立即清除。
- 主机编辑表单在保存失败（例如用户拒绝解锁）时保持打开，已填写的内容不会丢失。留空的秘密字段表示保留已保存的值。
- 主机编辑表单的"连接方式"可选直连、经跳板机（从其他已保存主机中选择）、HTTP 代理或 SOCKS5 代理（填写地址和端口）。经跳板机连接时，跳板机和目标的 host key 依次确认。
- `hostkey-prompt` 事件按到达顺序排队，逐个弹出确认框，显示算法和 `SHA256:` 指纹。关闭对话框视为拒绝。
- 侧栏底部显示 vault 状态。锁定时点击即请求解锁；设备密钥丢失时，确认后可以重置并丢弃已保存的凭据。
- 快速连接接受 `user@host:port` 等形式；不填密码时使用 SSH agent 和默认密钥文件，都不可用时询问密码。
- 读取私钥、agent、网络和 SFTP 类错误会在提示文字后附上后端给出的原因（如文件路径）。

## actions 表

`actions.ts` 是快捷键、命令面板、应用菜单和设置页快捷键列表的唯一来源。菜单结构在 `src/lib/menu.ts`（文件、编辑、视图、主机、帮助），每项只引用动作 id，文字和快捷键都取自动作表。新增应用快捷键时只在这里登记，不要在组件里单独监听按键。

- 绑定中的 `App` 在 macOS 上展开为 `Meta`（⌘），在其他平台展开为 `Ctrl+Shift`，因此普通的 Ctrl+字母总是交给 shell。
- 按键匹配使用物理按键（`event.code`），不受键盘布局和 Shift 的影响。
- 窗口在捕获阶段分发动作；终端通过 `isAppShortcut` 把这些按键让给应用。
- 标记了 `yieldsToTextField` 的动作（复制、粘贴）在终端以外的输入框获得焦点时不触发，交给浏览器的原生编辑行为。
- 终端程序自己维护选区时（Claude Code、tmux、vim）用 OSC 52 写剪贴板：只接受写入（`c;<base64>`，按 UTF-8 解码，最多 1 MiB），查询（`?`）一律不回应，程序读不到剪贴板（`terminal/osc52.ts`，有单元测试）。右键按下与松开不交给 xterm，因此不会上报给开启鼠标上报的程序（它会因此清掉自己的选区），只打开 RoveTerm 的菜单。
- 复制、粘贴快捷键只在属于终端时由应用处理（`terminal/claims.ts`，有单元测试）：复制要求聚焦终端有选区且页面别处没有选中文字（xterm 在终端内部留下的 DOM 选区不算）；粘贴要求焦点在终端（或页面主体）。其余情况不拦截，交给系统（如 AI 回复中选中的文字）。macOS 的"编辑"菜单先于页面拿到 ⌘C 时，文档级的 `copy` 事件把终端选区写入剪贴板。剪贴板读写都用原生插件（`ui/clipboard.ts` 的 `readClipboard` / `writeClipboard`，后者失败时退回网页接口）。
- `setOverrides` 用来替换用户自定义的绑定。

## 图标

界面图标只使用 Lucide（`lucide-static` 1.61.0，ISC 许可），在 `src/lib/ui/icons.ts` 中按含义命名后通过 `?raw` 导入；`Icon` 统一以 1.75 线宽、圆头圆角描边绘制，颜色取 `currentColor`。只有图标的按钮统一使用 `IconButton`，`label` 同时作为提示文字和无障碍名称。

主机的右键菜单由 `src/lib/hosts/hostMenu.ts` 的 `hostMenuItems` 生成，侧栏与主页卡片共用；主页空白处右键提供新建主机、快速连接、从系统导入、新建本地终端。文件管理器在行上右键作用于选择（未选中的行先被选中）：打开目录、下载、下载到、重命名、复制路径、删除；空白处右键：新建文件夹、上传文件或文件夹、刷新、显示隐藏文件。在空白处单击或右键会清除选择。

对话框（`Dialog`）挂载后移到 `<body>`：放在半透明面板（带 `backdrop-filter`）里的固定定位元素会以面板为参照被裁切。

右键菜单统一使用 `ContextMenu`：在指定坐标弹出并移到 `<body>`，自动避开窗口边缘，支持方向键和 Enter，选中、Escape、点击别处或窗口缩放时关闭。

不需要用户回答的通知统一用右上角的悬浮通知（`src/lib/ui/toast.svelte.ts` 的 `notify(message, kind)`，由 `Toaster` 绘制在对话框之上）：`info` / `success` 停留 4 秒，`error` 停留 8 秒且文字可选中；指针悬停时不消失，可手动关闭；最多同时显示 4 条，相同内容只重新计时。

WebView 的原生右键菜单在任何位置都不出现：`EditMenu`（挂在 `App` 上，监听 `window` 的 `contextmenu`）对没有被组件自行处理的右键调用 `preventDefault`；在文本输入框里右键弹出剪切、复制、粘贴、全选（密码框不提供剪切和复制），其他位置右键没有反应。

读取剪贴板统一走 `src/lib/ui/clipboard.ts` 的 `readClipboard()`（`tauri-plugin-clipboard-manager`，只授予 `allow-read-text`）：`navigator.clipboard.readText()` 在 macOS 的 WebKit 上每次都会弹出"粘贴"确认气泡。写入剪贴板仍用 `navigator.clipboard.writeText()`。

界面文字默认不可选中（`body` 设 `user-select: none`），与原生应用一致；输入框、文本域，以及需要复制的内容（加 `.selectable`：错误信息 `.error`、连接失败原因、主机指纹、密钥指纹）可以选中。

对话框统一使用 `Dialog`：打开时聚焦第一个输入控件，关闭时把焦点还给打开前的元素（通常是终端）；Escape 在窗口上监听，只关闭最内层的对话框，因此对话框内的焦点元素消失后仍然有效。

下拉选择统一使用 `src/lib/ui/Select.svelte`，不直接写原生 `<select>`：它按主题 token 绘制，列表以固定定位弹出，不会被对话框的滚动区域裁剪；支持方向键、Home/End、Enter 选择，Escape 只关闭列表。

## i18n

- `en.ts` 是源字典，定义 `MessageKey`；其他语言实现 `Messages` 类型，缺键会在类型检查时报错。
- `t(key, params)` 替换 `{name}` 占位符；`errorText(error)` 按 `CommandError.code` 查找 `error.<code>` 文案。
- 根据 `navigator.languages` 选择 `zh-CN` 或 `en`。

## 设计 token

组件只读取 `tokens.css` 中的 CSS 变量，不写死颜色、间距、圆角、阴影和动效时长。暗色主题跟随系统，也可以通过 `<html data-theme="light|dark">` 强制指定。

- 表面分层：`--window`（窗口底色）之上是半透明材质 `--material-sidebar` / `--material-bar` / `--material-popover`，配合 `--material-blur` 做毛玻璃；内容区用不透明的 `--surface` / `--surface-raised`。WebKitGTK 接受但不绘制 `backdrop-filter`，所以 Linux 上 `<html data-blur="off">`，弹层材质改为不透明。
- 窗口材质：启动时调用 `window_set_material`（`src/lib/ui/window.ts`），macOS 用侧栏毛玻璃（vibrancy；Liquid Glass 会清楚透出窗口后的内容，不用于整个窗口），Windows 11 用 Mica；Windows 10、Linux 和移动端返回 `false`，保持不透明。生效时 `<html data-material="on">`，`--window` 变为透明（macOS 上为 82% 不透明的底色，材质只带来淡淡的色调），侧栏和工具栏只做淡色叠加，内容区和终端仍不透明。窗口为此在 `tauri.macos.conf.json` / `tauri.windows.conf.json` 中设为 `transparent`。
- 标题栏以下，侧栏、工作区（标签栏、终端区与底部面板）、右侧面板是浮动的圆角卡片（`--radius-lg`），彼此及与窗口边缘相隔 `--gap-panel`，轮廓为 `--panel-shadow`；间隙露出窗口底色或系统材质。工作区与右侧面板之间的间隙本身就是拖动调整宽度的把手，悬停时显示强调色细线。
- 窗口顶部是 `TitleBar`（`src/lib/layout/TitleBar.svelte`，高 38px），空白处带 `data-tauri-drag-region`，可拖动、双击最大化；右侧是侧栏、底部面板、右侧面板三个布局开关。
  - Windows 与 Linux 不用系统标题栏（`decorations: false`，见 `tauri.windows.conf.json` / `tauri.linux.conf.json`）：左侧是 `menu.ts` 定义的文字菜单，点击展开、展开时指向其他菜单名即切换、左右方向键在菜单间移动；最右侧是自绘的最小化、最大化/还原、关闭按钮，最大化状态随窗口缩放更新。Windows 11 悬停最大化按钮时的贴靠布局弹窗因此不可用。
  - macOS 使用覆盖式标题栏（`titleBarStyle: Overlay`，隐藏标题），红绿灯画在标题栏左侧（`trafficLightPosition` 为 16, 19），标题栏左侧留出 80px，不显示文字菜单。菜单进入系统菜单栏：界面启动和切换语言时调用 `menu_set`，传入 `nativeMenus()`（`menu.ts` 中除编辑外的菜单，文字为当前语言）和系统项文字；应用菜单含关于、设置、隐藏、退出，编辑菜单使用系统预定义项（保证输入框原生复制粘贴），另有窗口菜单。选中动作项时后端发出 `menu-action` 事件，界面核对是动作表中的 id 后执行。绑定中含 ⌘ 的动作项带上快捷键（`accelerator.ts` 的 `menuAccelerator`，如 `Cmd+Shift+I`），菜单显示并处理它们，按键因此不会再进入网页，不会重复触发；不含 ⌘ 的绑定（如 `Ctrl+Tab`）和复制粘贴等也作用于输入框的动作不设快捷键，仍由动作表处理。后端校验快捷键只由字母数字和 `+` 组成，系统无法解析时该项不带快捷键，不影响整个菜单。
- 分隔一律用半透明细线 `--separator`（常以 0.5px 的 `box-shadow` 绘制），`--border` 只给输入类控件描边。
- 强调色只设 `--accent`，`--accent-hover`、`--accent-soft`、`--focus-ring` 等由 `color-mix()` 派生；状态色有 `--success` / `--warning` / `--danger` 及其 soft 版本。
- `--shadow-sm|md|lg` 是多层柔和阴影，`--glass-edge` 是玻璃边缘高光；动效用 `--ease` 与 `--dur-fast|dur|dur-slow`，系统要求减少动效时时长为 0。
- 外观偏好由 `applyAppearance()`（`src/lib/settings/appearance.ts`）在偏好加载和保存后应用：主题写入 `<html data-theme>`（跟随系统时移除），并通过 `setTheme` 让原生窗口外观跟随（Mica 与 macOS 材质取的是窗口外观，否则深色界面后面会透出浅色材质），非蓝色的强调色把 `--accent` 指向 `--sys-*`，界面缩放写入 `--ui-scale`（文字与控件高度按它缩放，终端字号不受影响），语言交给 `setLocale()`。
- 文案目录放在响应式状态 `locale`（`src/lib/i18n/locale.svelte.ts`）里，`t()` 读取它，切换语言后已渲染的界面随之更新，不需要重新挂载。
- 旧名 `--bg`、`--bg-elevated`、`--bg-sunken` 暂作别名保留。
- `controls.css` 的选择器都包在 `:where()` 里，没有优先级，组件自己的规则总能覆盖；自带外框的输入框（搜索框、路径栏）加 `class="bare"` 去掉文本框外观。开关用 `src/lib/ui/Switch.svelte`。
