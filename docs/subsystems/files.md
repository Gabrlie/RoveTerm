# 文件浏览与编辑

切换或刷新已列出的远程目录时，文件列表保留当前内容并显示加载进度。列表只采用最近一次导航请求的结果。

双击或按 Enter 打开常见的文本、代码和配置文件时，文件浏览器将不超过 2 MiB 的文件送入工作区编辑器。其他普通文件继续下载。每个草稿只开一个编辑器标签，未保存时标签显示圆点，关闭时可选择保存、放弃或取消。可从「文件草稿」重新打开本次运行中的草稿。工作区快照只保存可恢复的标签。

## 桌面外部编辑器

在「设置 → 文件」中留空自定义编辑器时，外部编辑与重新打开副本均使用系统文件关联。macOS 打开失败后改用默认文本编辑器。Windows 打开失败后显示「打开方式」选择器。Linux 通过 xdg-open 打开文件。

同一设置可指定本机编辑器的绝对路径及参数。工作副本、自动回传和冲突恢复规则见 [文本编辑](fs.md#文本编辑)。
