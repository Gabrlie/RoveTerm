# 系统图标来源

`osIcons.ts` 使用 24 × 24 的图标标识主机运行的系统。[Simple Icons](https://github.com/simple-icons/simple-icons) 16.35.0（`simple-icons` npm 包）的图标数据以 CC0 1.0 发布，商标归对应项目或公司所有。

- Proxmox VE 使用 Simple Icons 的 `siProxmox`，匹配 `proxmox` 和 `pve`。
- 飞牛 OS（fnOS）使用官方标志矢量路径（源自 [selfh.st/icons](https://github.com/selfhst/icons) `fnos.svg`，等比缩放到 24 × 24，品牌色 `#3374db`），匹配 `fnos` 和 `trim`。
