# 终端配色来源

`schemes.ts` 中 RoveTerm Light / Dark 为本项目自定，其余配色取自下列项目公开的颜色数值，均以 MIT 许可发布：

| 配色 | 来源 | 许可 |
|---|---|---|
| GitHub Light | https://github.com/primer/primitives | MIT |
| Solarized Light / Dark | https://github.com/altercation/solarized | MIT |
| One Dark | https://github.com/atom/atom（one-dark-syntax） | MIT |
| Dracula | https://github.com/dracula/dracula-theme | MIT |
| Nord | https://github.com/nordtheme/nord | MIT |
| Gruvbox Dark | https://github.com/morhetz/gruvbox | MIT |
| Tokyo Night | https://github.com/enkia/tokyo-night-vscode-theme | MIT |
